# Aetheria — Ecos da Aurora | P01 em construção

Este diretório contém **código-fonte real de um projeto Godot 4.x 3D**, integrado ao repositório Jhon. É uma **prova técnica**, não o RPG final. Os objetos da cena, inclusive Nóctis, são **geometria provisória**, em desacordo proposital com o acabamento final; NÃO devem ser divulgados como visual cinematográfico.

O objetivo do marco P01 é confirmar importação, movimento, câmera, colisão e controles touch. Depois substituir as malhas provisórias por personagens, cenários e animações de alta qualidade com direitos de uso validados.

Para rodar: abra `project.godot` no Godot 4.7.2 e pressione Executar. Verifique saída/erros. Para testar no Galaxy A15 é preciso exportação Android e validação em aparelho físico.
